# Pepsiversum – Verschlüsselte GitHub-Pages-Ausgabe

Diese Web-App enthält keine persönlichen Texte oder Daten im Klartext. `pepsi.enc` ist ein mit AES-256-GCM verschlüsselter Datenblock; die Entschlüsselung passiert lokal im Browser nach Eingabe des Passcodes.

`noindex, nofollow, noarchive` ist aktiv.
